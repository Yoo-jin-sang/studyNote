05-1. 형성

  1. 목차
    • 거미줄 형성
    • 꼬리표
    • 요소를 무리로
    • 요소에 상표를
  2. 본문
    • 거미줄 형성 - 전송 가능 모든 요소
    • 꼬리표 - <형성 속성="가">
      • 방법 - 시중자에 전송
        • 당도 - 내용 표출 ㅇ / 주소 표시줄
        • 우편 - 내용 표출 ㄴ
      • 이름 - 형성 이름 사용 / 자바스크립트
      • 행동 - 내용 처리 시중자 사용
      • 표적 - 대본 파일을 다른 창에서 표출
      • 자동완성 - 자동 완성 기능
    • 요소를 무리로
      • 분야설정
      • 전설
    • 요소에 상표를
      • 방법
        • 꼬리표 안에 형성 요소 - <상표>상표명</상표>
        • 꼬리표와 요소 따로 - <상표 목적="신분명">상표명</상표> - <입력 신분="신분명">
